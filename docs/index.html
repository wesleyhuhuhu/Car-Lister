Install the helper extension

Searching and Fetch options run from your browser, so you need the small Car Lister Helper extension (Chrome, Edge, Brave). Nothing else to install.

  1. Download the project (GitHub → Code → Download ZIP) and unzip it.
  2. Open chrome://extensions and switch on Developer mode.
  3. Click Load unpacked and pick the extension folder.
  4. Reload this page. The badge at the top turns green.

If the badge stays red, this site's address is probably not listed in the extension's manifest.json under content_scripts → matches. Add it and reload the extension.
