Install the helper extension

Searching and Fetch options run from your browser, so you need the small Car Lister Helper extension (Chrome, Edge, Brave). Nothing else to install.

  1. Download the latest car-lister-helper-….zip and unzip it somewhere you'll keep it (Chrome loads the extension from that folder).
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped car-lister-helper-… folder.
  4. Reload this page. The badge at the top turns green.

Updating: download the new ZIP, unzip it over the old folder (or load the new folder and remove the old one), then press the reload icon on the extension's card in chrome://extensions and reload this page.

If the badge stays red, this site's address is probably not listed in the extension's manifest.json under content_scripts → matches. Add it and reload the extension.
